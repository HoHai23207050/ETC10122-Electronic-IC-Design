# Coursework release index

Large assessed documents are distributed as versioned release assets. This
keeps the repository reviewable while preserving stable citations and hashes.

| Portfolio component | Public form | Purpose |
|---|---|---|
| Dual-port RAM project | PDF report, PPTX, DOCX | Design rationale, verified implementation evidence, and 10-minute defense material |
| ETC10122 exercises | PDF | Worked circuit-design and digital-flow exercises |
| 2020 examination | PDF | Fully developed solution and compact review material |
| Reproducibility source | ZIP archives | Permitted Typst source, assets, RTL, and scripts |

Lecturer-authored slides and the original examination scan are not
redistributed. The release provides student-authored work and a source map
without claiming ownership of the course material.
