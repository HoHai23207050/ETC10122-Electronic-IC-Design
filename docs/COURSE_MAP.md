# Course map and publication boundary

## Private course archive

The working archive contains lectures, exercise sheets, a previous examination,
student submissions, intermediate renders, OCR caches, and ASIC project files.
It remains the local source of truth for course study.

## Public repository representation

| Course area | Public representation |
|---|---|
| Dual-port RAM | Student-authored RTL, testbench, constraints, and portable flow scripts |
| Exercises | Assessed student solution PDF in the versioned release |
| 2020 examination | Student-authored worked solution in the versioned release |
| Lectures | A descriptive map only; lecturer files remain private |
| Report and defense | Final report, presentation, and English script in the release |

## Excluded material

- lecturer slides, tutorial PDFs, and examination scans;
- other students' submissions and class-wide archives;
- Synopsys executables, SAED libraries, rule decks, and PDK data;
- caches, extracted images, temporary builds, and duplicate drafts;
- unrelated coursework and scheduling files.

This separation preserves attribution, reduces accidental disclosure, and
makes every public artifact traceable to student-authored work.
